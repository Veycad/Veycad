# Проверка итогового релиза на телефоне

Это маршрут проверки, а не отчёт об успешном прохождении. Сейчас подписанного
кандидата нет. Проверки тестового APK отмечаются отдельно и не закрывают приёмку
версии, которая будет отправлена в магазин.

Для каждого прогона записать модель телефона, Android, наличие Google-сервисов,
свободное место, версию приложения, SHA-256 APK и отпечаток сертификата подписи.
Проверить как минимум ограниченный по ресурсам и современный физические arm64
телефоны; работу без Google-сервисов подтвердить отдельно.

## Что подготовить

- Разрешённое MP4/H.264 SDR-видео с хорошо видимым человеком и движением,
  длительностью 15–60 секунд. Для DUALITY — ещё один исходник 6–60 секунд.
  Простой пейзаж не является положительным тестом автоматических стилей:
  отказ из-за отсутствия человека может быть ожидаемым.
- Одно или два коротких MP4/H.264 SDR для ручного монтажа. Здесь подходят
  предметы и пейзажи; человек не обязателен.
- Ролик с понятной русской или английской речью и известным проверяющему текстом;
  отдельно ролик без речи. Только материалы, которые разрешено использовать.
- Сохранённый проект и настройки для проверки обновления; независимую резервную
  копию проекта до обновления. Не удалять установленное приложение и не очищать
  его данные ради устранения конфликта подписи.

## Порядок проверки

| Шаг | Действие | Что считать успешным |
| --- | --- | --- |
| Установка | Установить подписанный кандидат на чистое тестовое устройство или подходящее отдельное окружение | Версия запускается без отладочных экранов; вход в аккаунт приложения не требуется |
| Разрешения | Отказать в доступе, повторить нужное действие, затем дать необходимое разрешение | Нет падения или ложного сообщения об успехе; понятно, что нужно сделать дальше |
| Ручной монтаж | С главного экрана открыть «Довести монтаж», добавить видео, подрезать клип, изменить порядок и формат, отменить правку | Изменения соответствуют действиям; просмотр показывает нужные кадры; обрезка не меняет исходные файлы |
| Возврат к проекту | Выйти, открыть приложение заново и вернуться в редактор; повернуть телефон | Проект и правки сохранены; выбранный формат не меняется от поворота устройства; элементы управления доступны |
| Экспорт | Сохранить версию, открыть её внешним проигрывателем и отправить через системное меню | Получатель открывает настоящий MP4; видео не чёрное и не зависшее; звук слышен и соответствует монтажу |
| Автоматические стили | Отдельно пройти Heartbeat, FEAR и DUALITY на подходящих исходниках | Получен и просмотрен каждый MP4; склейки, кадрирование, эффекты и звук приняты владельцем. FEAR содержит вспышки — предупредить смотрящего до показа |
| Текст и речь | Открыть «Текст и субтитры», распознать речь, исправить фразу и её время, экспортировать; отдельно проверить тишину | Исправления попали в ролик, фразы читаются и соответствуют речи; на тишине нет выдуманных субтитров |
| Прерывание | Проверить уход в фон, блокировку и возврат при импорте/просмотре; отдельно выйти при экспорте | Нет повреждённого проекта или ложного успеха. Выход из ручного редактора останавливает экспорт, сохраняя черновик; после возврата экспорт можно запустить заново |
| Доступность | Увеличить шрифт до 200%, пройти основные действия с TalkBack | Подписи понятны, кнопки доступны, текущий шаг озвучивается; настройки телефона затем восстановлены |
| Съёмка | Если «Авто» доступен в кандидате, выполнить [отдельную приёмку камеры](../testing/auto-camera-device-review.md) | Реальные запись, выбор дубля, восстановление и готовый монтаж проверены; синтетическая камера эмулятора не засчитывается |
| Обновление | Установить следующую версию с тем же сертификатом и большим номером версии | Настройки, проекты, исходники и резервные копии сохранены; проект открывается и экспортируется. Следовать [процедуре обновления](../testing/project-backup-recovery.md#signed-update-and-corrective-release-procedure) |

Для обещания работы без интернета повторить импорт, распознавание и экспорт без
сети. Отсутствие разрешения INTERNET в APK само по себе не подтверждает работу
всех локальных моделей на физическом устройстве без Google-сервисов.

## Как записать результат

По каждому шагу: **пройдено / ошибка / не проверено**, фактический результат и
ссылка на локальное доказательство. Для готовых MP4 сохранить имя файла,
SHA-256, длительность обработки и отзыв владельца о картинке и звуке.
Отдельно отметить полное декодирование файла, синхронизацию и корректность
выбранного формата. Автотест или сам факт появления файла не заменяет просмотр.

Ожидаемый отказ на неподходящем исходнике записывать отдельно от успешного
монтажа: это проверка объяснения ошибки, а не подтверждение качества стиля.
Любое падение, потеря проекта или невозможность основного экспорта блокирует
релиз. Непроверенные пункты остаются открытыми. Личные видео не публиковать
в PR или карточке магазина без отдельного согласия.
