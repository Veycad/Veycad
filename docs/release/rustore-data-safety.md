## Что указать и почему

RuStore просит отметить типы данных, к которым приложение получает доступ.
Предзаполненный по разрешениям список нужно проверить: выбор файлов и ввод текста
не обязательно требуют отдельного разрешения Android. Ниже — сопоставление
функций Veycad с категориями, а не утверждение об отправке данных разработчику.

| Категория для сверки в консоли | Реальное поведение Veycad |
| --- | --- |
| Видео | Читает выбранные исходники, создаёт рабочие копии, анализирует изображение и сохраняет результат локально. Камера используется для съёмки внутри приложения. |
| Аудиозаписи, музыкальные и другие аудиофайлы | Обрабатывает звук выбранных роликов и импортированную музыку, локально распознаёт речь. Доступ к микрофону текущий APK не запрашивает. |
| Файлы и документы | Импортирует и экспортирует проекты; архив может включать исходные медиа. Рабочие данные и имена файлов сохраняются в приватном хранилище. |
| Другой пользовательский контент | Хранит введённые заголовки, исправленные субтитры и параметры монтажа в проектах. |
| Диагностика, отчёты об ошибках, взаимодействие с приложением | Локальный журнал содержит события, технические параметры и ошибки. Общий журнал может включать имена файлов и сообщения ошибок; автоматически он не отправляется. |
| Идентификаторы | Общий локальный журнал использует случайный идентификатор диагностической сессии. Это не аккаунт и не рекламный ID. Экспортируемый через интерфейс отчёт о съёмке этот идентификатор не включает. |

Извлечение позы, лиц и масок выполняется на устройстве для монтажа; это нужно
описать в политике. Не заявлять распознавание личности или создание аккаунта:
таких функций в проверенном приложении нет.

## Передача и удаление

Автоматической отправки разработчику нет. В проверенном APK отсутствуют
`INTERNET` и `ACCESS_NETWORK_STATE`. При явном сохранении или отправке пользователь
выбирает внешнее хранилище либо приложение: передаваться могут готовый ролик,
архив проекта с исходниками или отдельный технический отчёт о съёмке.
Состав отчёта ограничен разрешёнными полями; медиа, пути, имена файлов и свободные
сообщения ошибок исключены. Внешний получатель действует по своим правилам.

Не переносить автоматически ответ «передачи нет» на пользовательский экспорт:
сверить определение передачи и варианты ответа в фактической консоли.

Очистка временных файлов сохраняет завершённые монтажи и не удаляет все проекты
и журнал. Очистка данных через Android удаляет приватные данные приложения;
файлы, ранее сохранённые вне него, удаляются отдельно.

## Разрешения проверенного APK

`aapt2 dump permissions` для универсального V11 показал:

- `CAMERA` — съёмка внутри приложения; импорт и редактор доступны без камеры.
- `POST_NOTIFICATIONS` — уведомления о работе приложения.
- `WAKE_LOCK` — длительная локальная обработка.
- `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE` — из объединённого манифеста зависимостей.
- `com.veycad.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` — собственное signature-разрешение.

Нет `RECORD_AUDIO`, разрешений чтения всей медиатеки, контактов или геолокации.
Список чувствительных разрешений определяет консоль после загрузки: дать
обоснование каждому обнаруженному разрешению, не добавляя вымышленных функций.

Контрольная сумма APK и границы проверки: [отчёт V11](integration-2026-11-02-v11.md).
