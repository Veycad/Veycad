# Конфиденциальность Veycad — проект для первого релиза

Статус: не опубликованная политика. Основание — код `beca0960` и проверенный unsigned release
0.1.16 (17). Перед публикацией сверить с итоговым подписанным APK, указать дату
вступления в силу и постоянный публичный адрес документа.

## Текст для пользователя

Разработчик Veycad — Leonid Polyakov. Поддержка и вопросы об обработке данных:
[whiteking.power12@gmail.com](mailto:whiteking.power12@gmail.com).

Veycad обрабатывает выбранные видео и аудио на вашем устройстве. Для создания монтажа
приложение анализирует изображение, лица и положение тела, обрабатывает звук и при использовании
субтитров распознаёт речь. Учётная запись для работы приложения не нужна.

Приложение не отправляет исходники, кадры, звук и готовые монтажи на сервер разработчика.
В текущей Android-сборке отсутствует разрешение доступа в интернет. Вы сами выбираете файлы
для импорта через системное окно. Для съёмки внутри приложения требуется доступ к камере.

В приватном хранилище приложения сохраняются рабочие копии файлов, проекты, результаты,
настройки и технический журнал. Журнал помогает разбирать ошибки и включает сведения
об устройстве, версии приложения и событиях работы; отдельные события могут содержать имена
файлов и сообщения ошибок. Автоматической отправки журнала разработчику нет.

При сохранении или отправке ролика вы выбираете место или приложение-получателя.
Архив проекта может содержать исходные видео и аудио. Отчёт о съёмке экспортируется отдельно
по вашей команде: он содержит технические сведения и события съёмки, но исключает медиа,
имена и пути файлов и произвольные сообщения ошибок. Выбранное вами внешнее приложение
или файловое хранилище может передавать эти файлы по своим правилам.

Очистка временных файлов в Veycad сохраняет готовые эдиты и не удаляет все данные приложения.
Чтобы удалить приватные данные целиком, используйте очистку данных приложения в настройках
Android. Ранее сохранённые в галерею, экспортированные или отправленные файлы удаляются отдельно.
