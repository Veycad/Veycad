# Совместимость AAC и проверка кандидата #120

Сверка 2026-11-09. Код: `931e5300594d6f49c723497c347ec35c7345c0dd`,
[draft PR #120](https://github.com/Veycad/Veycad/pull/120).
Результаты сборки и CI датированы 2026-11-02; это не готовность к публикации.

## Изменение

Подготовленный экспорт с исходным звуком раньше отклонялся до API35.
Экспорт только с музыкой уже имел отдельный путь. Теперь подготовленные
миксы используют общий калиброванный AAC-путь: Media3 muxer до API35,
системный MediaMuxer на новых Android. Runtime-зависимости не расширены:
Media3 уже приходил через CameraX.

Поддержаны 64-битные MP4 edit lists и особенности старого MediaExtractor.
Проверки количества PCM-кадров, контрольных меток, исходных байтов,
отмены и очистки сохранены. API28 не доказывает весь диапазон API26–34/OEM.

## Подтверждённые результаты

- Чистый `baselineVerify` и release/UI/instrumentation-сборки точного коммита:
  1397 JVM + 338 Python, без ошибок; общее время 8м19с.
- Локальный официальный Android9-набор: 8/8; контроль тех же APK на API36:
  4/4. Проверены ручной редактор, исходники, экспорт, повторное открытие,
  передача файла, SOURCE/MUSIC, пиксели, тайминг и отмена. Runtime APK были
  собраны до коммита; соответствие исходных файлов сохранено отдельно.
- Окончательные четыре unsigned APK содержат правильные package/version/ABI,
  SHA исходного коммита, включённый редактор, проверенную модель Whisper и файлы
  уведомлений о лицензиях.
  Debug и сетевые разрешения отсутствуют. Все четыре прошли `zipalign -c -P 16`;
  14 уникальных 64-битных библиотек прошли проверку ELF LOAD-выравнивания.
  Это статическая проверка, без установки подписанного release APK.
- Локальное независимое декодирование ручного 1080p-экспорта API28:
  видео и аудио по 6,000 с.

## Последний полный CI

[Android UI #120](https://github.com/Veycad/Veycad/actions/runs/41447922975)
завершился: permissions 2/2, screens **277/278**, 0 errors/skips.
Единственный отказ — `ManualMvpScreenTest.importFourFormatsTrimUndoReopenAndLandscapeExportShareOneRevision`:
ожидание публикации экспорта истекло. Причина не установлена; срок ожидания
и критерии не ослаблялись. Ошибка прямого предпросмотра из #119 в этом
прогоне не повторилась, что не доказывает устойчивого устранения.
Android9 job `legacy-save` успешен; baseline тоже успешен.

Последующий шаг независимой проверки AAC в CI не смог скачать FFmpeg:
соединение с ffmpeg.org завершилось timeout/reset. Сохранённые AAC/MP4 этого
же прогона проверены локально тем же скриптом с FFmpeg9.0.2. Хэши сверены
с записанными на устройстве; все четыре файла дали ровно 48000 PCM-кадров
и метки 1600/24000/46400. Смешанный AAC: пик 0,89218, без серии насыщенных
сэмплов. Этот результат не превращает неуспешный UI job в успешный.

## Локальный контроль и диагностика #121

Локальный API36/Windows SwiftShader-прогон исходного проблемного сценария
прошёл 1/1 за 306,095 с с прежним кодом и deadline. Сохранённый MP4 полностью
декодирован: 1920×1080, 179 видеокадров, 286400 стерео PCM-кадров;
обе дорожки 5,966667 с. Это не воспроизведение и не устранение сбоя Linux CI.
Снимки потоков в 90/180/240 с показывают разные фазы работы, включая
кодирование и последующий предпросмотр; они не доказывают зависание драйвера.

[Draft PR #121](https://github.com/Veycad/Veycad/pull/121), `215a5cb`, меняет
только диагностику двух тестов. Условие успеха и 180 с сохранены. При отказе
будут видны отдельно связанные экспортные файлы, состояние редактора и
GL/audio-потоки. Новый helper прошёл функциональный native-сценарий 1/1
за 154,015 с; ветка формирования ошибки пока не срабатывала в native-прогоне.
Полные baseline/UI для #121 запущены; результат ещё не подтверждён.

## Распознавание речи с 16 КБ страницами

На API35/x86_64 с эмулируемым 16 КБ userspace прошли все пять сценариев
`WhisperDeviceTest`: английский/русский, тишина, перекрывающиеся окна длинной
записи, неверный вход и отмена native-распознавания. Итог: 5/5, 0 errors/skips,
241,361 с. Перед запуском проверен фактический `getconf PAGESIZE=16384`.
Точный тестовый APK приложения прошёл ZIP/ELF-проверку всех семи x86_64 библиотек.

Это UI/debug-вариант приложения `931e530` с тестами #121. Его собственные
`libveycad_whisper.so` и `libveycad_preview_memory.so` отличаются от release
бинарно; результат не переносится на подписанный release или физический ARM.
Остальная runtime-приёмка 16 КБ остаётся открытой.
