# Презентация Veykad

`Veykad_Overview_RU.pptx` — девять слайдов на русском для внешнего знакомства
с приложением. Формат 16:9, редактируемый текст, встроенные скриншоты интерфейса.

Содержание сверено 2 октября 2026 года с текущим рабочим деревом AutoEdit,
которое содержит ещё не опубликованные изменения. Основные источники:
README.md, docs/SupportMatrix.md, MainActivity.kt, MontageStyleCatalog.kt,
MontageStylePresentation.kt, BuiltInMusicCatalog.kt, MontageFailurePresentation.kt
и AndroidManifest.xml. Подробные ссылки на источники указаны в заметках слайдов.
Презентация описывает локальную рабочую версию, а не только первоначальный
коммит main. Это изменение не переносит код приложения в удалённый репозиторий.

В презентации доступны Heartbeat, FEAR и DUALITY. Сигма обозначена временно
недоступной. Планы новых функций и экспериментальная камера отдельной
установленной пилотной сборки не заявлены как функции основной версии.
Полностью принятый публичный релиз и универсальная поддержка устройств
не заявлены. Скриншоты взяты из docs/design/approved, сентябрь 2026 года,
с кадрированием для показа соответствующих элементов интерфейса.

Проверки: структура пакета PPTX, геометрия слайдов и шрифты прошли встроенный
финализатор. Итоговый файл повторно импортирован Artifact Tool и все девять
слайдов отрендерены для визуального просмотра. Обложка исправлена после
просмотра. Проверка в самом Microsoft PowerPoint не выполнялась.
Android baselineVerify не запускался: код приложения не изменён.
