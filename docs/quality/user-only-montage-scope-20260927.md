# Только присланные пользователем тестовые видео

Действующее указание пользователя от 2026-09-27: «Используй в монтаже
только видео которые я тебе отправлял в виде тестовых».
Оно ограничивает все последующие монтажи, включая проверочные экспорты.
Открытые источники, синтетические видео и производные от стороннего материала
не заменяют присланные тестовые исходники. Искусственные данные в модульных
тестах не являются монтажами и не доказывают качество на реальном видео.

### Последующее явное разрешение на остальные стили

На уточнение пользователь ответил: «Используй те же что и для Duality,
чередуй их». Теперь оба указанных оригинала разрешены также для Sigma,
Heartbeat и FEAR. Чередование означает смену исходника между прогонами
одного стиля: A, затем B. Каждый одновходовый продукт получает один файл,
не новую неподдерживаемую двухвходовую схему. DUALITY получает оба вместе.
Первоначальная таблица выше отражает назначение при присылке, а не нынешнее
ограничение стилей. Расширение относится только к этим же точным хешам;
другие видео автоматически не разрешаются.

## Сторонние проверки прекращены

После восстановления эмулятора: загрузка завершена, процесс приложения
отсутствует. У прежнего стороннего Heartbeat-прогона
`calibration_v17_heartbeat_fresh_face_20260927.mp4[.result]` нет ни MP4,
ни финального маркера. Это прерванный запуск, не успешный результат и не
подтверждённый отказ по качеству материала. Он не возобновляется.

Ранее скачанные публичные материалы и исторические отчёты сохранены, но
исключены из последующего монтажного протокола. Исторические результаты
не переписываются и не превращаются в результаты на пользовательских видео.
Новые скачивания для монтажа не выполняются.

Локальный помощник `tools/quality_user_source_guard.py` проверяет реальные
байты, назначение стиля и две различные идентичности для DUALITY. Проверка
на двух настоящих локальных копиях прошла; первоначальные 12 новых тестов и
вся Python-серия из 127 тестов прошли до расширения разрешения стилей.
Это предварительная проверка рабочего протокола, не
встроенная блокировка приложения. Копии на устройстве и их неизменность
нужно дополнительно сверять перед каждым экспортом.

После явного расширения разрешения оба хеша доступны во всех четырёх
рецептах. Sigma/Heartbeat/FEAR требуют ровно один файл на запуск. Для
чередования передаётся SHA фактического предыдущего одновходового прогона;
повтор того же исходника отклоняется. Без истории чередование не объявляется
проверенным. 18 тестов помощника и полная Python-серия из 133 тестов прошли.

## Граница приёмки

Автоматические тесты, повтор известной пары и проверка хеша не закрывают
независимую разнообразную серию или художественную приёмку человеком.
Для расширения серии нужны дополнительные лично присланные пользователем
тестовые видео с подтверждённым назначением. Общая готовность четырёх
стилей остаётся 0/4; требования к качеству не ослабляются. Sigma только
приостановлена, не удалена из полной исходной цели; release ready не достигнут.
