# Локальное соответствие кадров для интенсивности движения

Историческая запись отдельного компонента до интеграции. Текущее
подключение к производственному анализу и FEAR: `person-motion-production-v6.md`.

Реализован `LocalMotionCorrespondence`, отдельный от blur-flow редактора.
Компонент ещё не подключён к производственному анализу или FEAR gate.
Он выдаёт для каждой ячейки фактический центр, нормированный displacement
и индивидуальную confidence — не размноженную global flow confidence.

Патчи сравниваются после вычитания собственной средней яркости, чтобы
общий аддитивный lighting offset не превращался в displacement.
Confidence требует текстуру, малую ошибку совпадения, уникальность
лучшего кандидата и согласованность forward/backward correspondence
в пределах одного пикселя. Плоский/неоднозначный патч не даёт поддержки.
Метод ограничен grid/search/patch radius; это локальный block matching,
не точный ground-truth optical flow или обученный per-person motion model.

Параметры нового измерения явны: default grid 12×18, search radius 3 px,
patch radius 2 px; texture cutoff 0.02, fit-error scale 0.05,
uniqueness-margin scale 0.02. Это инженерные начальные критерии confidence,
проверенные на контролях, не откалиброванная вероятность и не новый
релизный успех на независимых съёмках. Порог FEAR 0.18 не менялся.

Восемь pixel-level тестов: неподвижная текстура, camera translation,
общая смена яркости, независимый noise, flat flash, отсутствие предыдущего
кадра, повторяющиеся stripes и два встречных текстурированных объекта.
В первоначальном генераторе «noise» seed менял начало структурированной
последовательности: это не независимая пара. Он заменён разными seeded
Random-последовательностями; неоднозначная периодика проверяется отдельно.
Критерии matcher ради зелёного теста не ослаблялись.

Для двух объектов, сдвинутых на ±2 px, correspondence + intensity
дали 0.6666667 (нормировка 2/3), 32 поддержанные ячейки,
supported person fraction 0.5925926. Маски прокси-объектов и неподвижная
камера известны из синтетической сцены — это не успешная ML-оценка людей.
Full unit suite: 339 tests, 0 failures/errors.
