## Границы доказательства

Это preregistered pilot-серия на неполном доступном наборе, НЕ sealed holdout.
С началом native анализа C весь её родитель консервативно выводится из unused-кандидатов
в pilot; после терминального результата добавляется привязка к реальному raw-result.
Ни C, ни A/B после этого не закрывают
независимую разнообразную приёмку. Полная исходная цель не уменьшается.

Успех означает отдельные реальные машинные измерения для каждого продукта:
fresh decoded face, реальные PTS/контейнер, граф и повтор случайных исходных
окон, собственные ритм/структура/переходы, полный Heartbeat blacktail и
самостоятельно декодированный unclamped float-AAC. Неизменённые критерии
проверяет `quality_render_report.py`; отказ сохраняется с фактическим кодом,
unknown движения не объявляется статикой. При наличии MP4 создаётся новая
пустая output-bound форма просмотра1×/0.5×; при материальном отказе — пустая
negative-review. Старые оценки WhiteKing не переносятся.

Перед первым запуском будет сохранён новый архив baseline-v23 текущих
app/tools/docs/quality и настроек сборки, включая грязную рабочую копию.
Его SHA будет записан отдельно. Это снимок pilot-серии, не успешный seal.
Новая сборка/загрузка на Яндекс Диск этим планом не производится.
