# Открытые пилоты качества

Это диагностические прогоны, **не** слепая приёмка и **не** основание считать
качество продукта подтверждённым. Использованный родительский материал выводится
из holdout; результирующие MP4 и детальные отчёты остаются в локальном
игнорируемом `artifacts/quality/runs/`.

  Этот источник не подтверждает пригодность для положительного Sigma-теста,
