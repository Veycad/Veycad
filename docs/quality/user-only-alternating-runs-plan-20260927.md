# Чередование разрешённых пользовательских исходников

Пользователь явно разрешил те же файлы для всех стилей и попросил чередовать.
Все будущие монтажи используют только подтверждённые оригинальные SHA из
`user-only-montage-scope-20260927.md`. Музыка берётся отдельно для каждого
стиля. DUALITY остаётся двухвходовым; остальные стили — одновходовыми.

После последующего изменения цели работа над Sigma приостановлена и
пользовательский запуск этого режима должен быть заблокирован. Sigma
исключается из монтажных прогонов. После устранения текущей ошибки второго
входа первая последовательность одновходовых прогонов:
Heartbeat(A), FEAR(B), FEAR(A), Heartbeat(B), затем DUALITY(B,A).
Источники чередуются между последовательными одновходовыми прогонами,
и каждый из двух активных одновходовых стилей проверяется на обоих файлах.
DUALITY не меняет историю одновходового чередования.
Это план, не сведения о запуске.
Успешные и отвергнутые попытки обе входят в историю чередования; повтор
не запускается под прежним именем. DUALITY между ними использует оба файла
и не подменяет запись предыдущего одновходового исходника.

Перед каждым одновходовым запуском помощнику передаётся SHA действительно
предыдущего одновходового прогона. Для первой попытки история отсутствует
и это явно отмечается. Дополнительно сверяются эмуляторные входы, музыка,
точная сборка, отсутствие текущего рабочего потока и новых целей/маркеров.
Названия выходов фиксируются перед фактическим запуском с новой ревизией.

Исходник B длится около 14.42 с. Если длительность или реальная семантика
не удовлетворяет стилю, фиксируется настоящий отказ без растягивания
исходника, синтетического движения или ослабления условий. Нельзя объявлять
все выбранные материалы заранее подходящими. Одна уже знакомая пара не
покрывает независимый разнообразный корпус. Все человеческие оценки новой
сборки остаются незаполненными до реального просмотра новых MP4.
