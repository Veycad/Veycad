## Десять пунктов для каждого файла

Ответ для каждого: «пройдено», «не пройдено» или «не могу подтвердить».
Если есть проблема, укажите время и что заметили.

1. Выбор кадров: нет случайных/неуместных моментов или мешающего однообразия.
2. Композиция: герой и лицо читаемы; обрезка не мешает смыслу/жестам.
3. Склейки: нет технических сбоев или неуместных переходов.
4. Ритм: смена планов и движения согласованы с музыкой.
5. Цвет: нет мешающих скачков света/цвета между фрагментами.
6. Музыка: нет слышимых искажений, случайного обрыва или сдвига.
7. Финал: завершённый, без случайного зависшего кадра; чёрный хвост здесь намеренный.
8. Повтор фразы: вторая часть узнаваемо возвращает первую, а не повторяет случайно.
9. Эхо: лицо читаемо при двойном изображении, нет мешающего слияния слоёв.
10. Пульс и чёрный финал: акценты уместны, завершение воспринимается намеренным.

Для фиксации нужны имя/псевдоним, дата/время с часовым поясом, отдельное
подтверждение двух скоростей и ответы на10пунктов для каждого файла.
Неизвестный пункт не считается пройденным; общий «хорошо» не заполняет10проверок.
