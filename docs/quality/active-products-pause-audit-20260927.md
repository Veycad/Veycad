# Границы текущей приёмки при паузе Sigma

Пауза Sigma подтверждена указанием пользователя, каталогом доступности,
общей границей редактора и реальным интерфейсом доставленного APK0.1.1.
Блокировка не является положительной оценкой качества монтажа Sigma.
Новые прогоны Sigma запрещены; Heartbeat, FEAR и DUALITY проверяются отдельно.

Read-only аудит обнаружил ограничение текущего quality_release_matrix.py:
он всё ещё требует все четыре исходных продукта и выдаёт только общий ready.
Его отрицательный результат не означает необходимость возобновить Sigma
вопреки пользователю. Нельзя молча удалить Sigma или остальные обязательные
пункты из манифеста, чтобы получить зелёный результат.

Полная готовность четырёх продуктов остаётся ложной при паузе Sigma.
Будущая отдельная активная матрица должна явно сохранять все четыре ключа,
Sigma=paused_not_release_ready с пользовательским основанием, отдельное
active_products_ready для остальных и связывать scope с фиксацией до
раскрытия результатов. Нельзя произвольно ставить на паузу не прошедший
Heartbeat/FEAR/DUALITY через per-case исключение. Исторические seal/matrix
сохраняются; в этом аудите код матрицы и пороги не менялись.

## Что ещё требуется активным продуктам

- Не менее трёх независимых положительных родительских съёмок для каждого
  активного одновходового продукта и трёх осмысленных пар DUALITY, обе
  последовательности импорта каждой пары.
- Настоящие короткие/no-person отказы каждого активного продукта; FEAR
  дополнительно insufficient_motion и insufficient_distinct_moments.
- Девять условий исходной цели, 24/25/30/60 fps, MP4/WebM/MOV, CFR/VFR,
  минимум две подтверждённые модели камеры, новые ещё не использованные
  родители с фиксацией APK/критериев до первых результатов.
- Для каждого положительного результата: реальный MP4 и текущая идентичность
  APK/device/source/music, существующие продуктовые gates, независимый AAC,
  действительный датированный просмотр 1×/0.5× с общими/стилевыми пунктами.
- Для отрицательного: точный raw-код, отсутствие MP4, новая человеческая
  оценка материала и сообщения, связанная с hash raw/recipe/ordered sources.

Знакомая присланная пара A/B — только калибровка. Её чередование/переворот
не создаёт новые независимые родители. Публичные замены запрещены текущим
указанием пользователя. Полные исходные требования не сокращаются;
неисполненные требования Sigma отложены, а не пройдены.
