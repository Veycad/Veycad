## Метод и следующий безопасный шаг

Поиск выполнен через web search; вывод опирается на реальные Commons file pages,
их фиксированные revisions и публичный API `prop=imageinfo|revisions`,
`iiprop=url|size|sha1|mime|timestamp|metadata`, `rvprop=ids` для шести точных titles.
Пример первичного [API imageinfo для UAE01](https://commons.wikimedia.org/w/api.php?action=query&format=json&prop=imageinfo%7Crevisions&rvprop=ids&iiprop=url%7Csize%7Csha1%7Cmime%7Ctimestamp%7Cmetadata&titles=File%3ABelly_dancer_UAE_2012_01.webm).
На этапе поиска API responses прочитаны в памяти, видео/аудио не загружены. Первая
полная печать metadata была обрезана; затем повторно получены только нужные
поля без обрезания. URL выше сохраняют original-file путь из API без tracking
query. На этом этапе их доступность/байты загрузкой не проверялись. Позднейшие
локальные SHA-256/decode/PTS приведены ниже; Android-совместимость и
положительная visual/human приёмка всё ещё отсутствуют.

Практический приоритет — проверить provenance двух сильных групп (Fabiola и
R16), а не начинать новые случайные пары. UAE остаётся условным третьим lead;
если отдельность записей/общий персонаж не подтверждаются, искать замену.
Общее число исследованных групп3 не означает три готовых независимых пары.
Разные авторы/страны/годы дают основания заявленных разных родителей, но
разные camera models и освещение не доказаны и здесь не засчитаны.

После подтверждения прав/связи: отдельная будущая загрузка неизменённых
publisher bytes, сверка size/SHA-1 и локального SHA-256, проверка родства/
дубликатов с текущими pilot/holdout, source-only условия, новый кандидатный
манифест и точная фиксация ДО моделей/директоров. Одну связанную сессию считать
одним parent для single-style, обе перестановки каждой DUALITY-пары — отдельно.
Не использовать исследовательские ID как уже принятую release matrix.

Проходят только четыре собственные грамматики, actual MP4/AAC gates и честная
человеческая приёмка. Длительность, licensed download URL, названный танец или
авторский caption не доказывают непрерывный FEAR opener, контраст каскада,
устойчивую маску Sigma, узнаваемую репризу HB или музыкальную игру DUALITY.
