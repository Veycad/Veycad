# Разделение измерения маски и её настоящих дефектов

## Изменение после завершённого calibration v2

v2 исправила временную выборку, но прежние mask/beat значения остались
непринятыми. Новый код различает пять состояний mask QA:
`NOT_REQUESTED`, `MEASURED`, `SOURCE_MASK_EMPTY`, `OUTPUT_MASK_EMPTY`,
`INFERENCE_FAILED`. Это доступность измерения, не оценка художественного
качества или автоматическое доказательство утечки.

Производственный sampler записывает явный статус каждой попытки. Пустая
projected/source маска, пустой распознанный выход и ошибка/невалидный буфер
получают отдельные причины отказа. Неизмеренные/пустые маски не участвуют
в сравнении temporal IoU; история сравнения сбрасывается, чтобы ошибка
распознавания не превращалась в искусственный дефект устойчивости.
Требование наличия измерения и временной проверки сохранено.

Если контур действительно измерен, применяется прежний leak-порог 0.02
и temporal IoU 0.88. Conservative edge=1 при недоступном измерении
сохраняется в числовом отчёте, но Android issue больше не называет этот
sentinel настоящей утечкой: есть отдельный код причины. Считать числовой
максимум без статусов доказательством пиксельного дефекта нельзя.

Debug-отчёт содержит число measured/source-empty/output-empty/inference-failed
samples и времена неуспешных измерений. Новый offline Sigma gate требует
хотя бы один измеренный sample и нулевые счётчики трёх отказов. Старые
отчёты без этих полей не подтверждают новую версию. Это усиление проверки
доступности, не ослабление прежних числовых порогов; старые критерии v1/v2
сохранены в их baseline-архивах.

Прогон завершён в 13:05 UTC, поток PID 12289 / TID 12308 исчез,
MP4/финальный отчёт получены. Runtime APK совпал с v3, split APK 0,
модель эмулятора и API 36 совпали. Выход SHA
`3905809ac9aa9efa334c1519032b90596c3545b70e565bd66efd32c9ea79a5ec`.

27 source-mask samples, но успешных measured output samples — 0.
Source-empty 0, inference-failed 0, output-empty 3:
1.800, 1.900, 2.000 с. Источник маски поддержан, но распознавание готового
тёмного вступления не даёт контура с confidence >= 0.5. Это не доказанный
pixel edge leak и не доказанная геометрическая нестабильность.
Результат не различает тёмного/нечитаемого персонажа в рендере и слепоту
output-сегментера: нужна независимая пиксельная/визуальная проверка.

Android gate отказал с `foreground-mask-measurement-missing`,
`foreground-mask-output-empty`, `foreground-mask-temporal-evidence-missing`.
Ложное именование edge=1 как измеренной утечки заменено конкретной причиной.
Числовые conservative sentinels max-edge=1/min-IoU=0 не дают успеха.
Offline дополнительно отверг measured count=0 и output-empty count=3.
Beat-hit 0.06666667 и author-accent-hit 0.22222222 также не проходят;
исправление диагностики не выдаётся за улучшение ритма или маски.

Полное декодирование видео v2 и v3 одним FFmpeg в rawvideo с passthrough
дало одинаковый SHA всех пикселей:
`b2ce7d041c4a4354c2610ce9c504db07e02558e3c110ff1ca7fdcae5144a0224`.
Это подтверждает, что изменилось измерение/объяснение отказа, не картинка.
Контейнерные SHA отличаются, поэтому одного сравнения MP4 SHA было бы мало.

Фактический AAC прошёл float decode, peak 0.803217, non-finite/
over-full-scale/plateau 0. `resolved_unknowns=[]`, так как есть другие
причины отказа. Создана отдельная пустая выход-привязанная review-форма;
`machine_and_human_pass=false`. Этот calibration-результат не добавлен
в release matrix v1 и не заменяет новую независимую приёмку.
