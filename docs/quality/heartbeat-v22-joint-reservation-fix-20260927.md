# Heartbeat: исправление совместного выбора live-интервалов

Основание — реальный v21 экспорт A с 347 мс случайных пересечений первой
фразы, repeated_source_ratio0.029531915 при пороге0.02. Предыдущий APK0.1.1
доставлен и сохранён отдельно; не объявляется исправленным задним числом.

Новая локальная версия0.1.2/code3 собрана и проверена. Фактический экспорт A
и независимый звук завершены; измеренное случайное пересечение authored
интервалов0.0. Человеческая приёмка художественной структуры ещё отсутствует.

## Изменённый контракт выбора

- Резервируются максимальные реальные uses, включая финал1133мс на фактически
  выбранном hero role4, а не прежнем authored role14.
- После композиционной перестановки интервалы выбираются совместно:
  читаемые расширения/сдвиги учитывают уже занятое время и исходную идентичность.
- Если предпочтительное назначение не помещается, проверяются совместимые
  обычные роли с сохранением измеренного героя; затем допустимый исходный герой.
- Каждый визуальный слот имеет source duration=output duration, constant1×.
  Нельзя выдавать укороченные/замедленные исходные окна за исправление повтора.
- HB-specific source pool выбирает непересекающиеся окна. Общий FEAR-selector
  не меняется. Optional interlude допускается только на свободном интервале;
  unknown face не заменяется measured empty. Это консервативная вставка,
  не доказанный глобальный художественный оптимум.
- Разрешённая реприза,27клипов,1270кадров, часы/музыка/чёрный хвост сохранены.
  Численный gate0.02 не меняется; планировщик гарантирует более строгую
  нулевую случайную долю пересечения. Если нет подходящих handles —
  insufficient_distinct_moments до экспорта, не искусственный материал.

Перебор использует точное свёртывание вариантов с одинаковыми конфликтами,
проверку возможного взаимно-однозначного назначения source-role и необходимой
доступной длительности. Произвольного production timeout/search cap нет.
Обнаруженный в тесте долгий поиск на реальных v21-интервалах устранён
эквивалентным сокращением задачи. Проверка этой раскладки прошла за69мс
в конкретном JVM-прогоне; это не универсальная гарантия времени на всех входах.

Shift/profile-gap controls остаются строгими сравнениями и могут честно
отказаться. Совместимое переназначение может различаться между controls;
не заявляется одинаковый выбор источников без сравнения реальных графов.
Фрейминг светового портрета использует окончательно выбранный интервал.

## Доказательства и ограничения

59 focused JVM-тестов пройдены. Предыдущий полный прогон обнаружил один
старый тестовый pool1000мс без evidence для1133мс финала; только Heartbeat
fixture этого теста усилен до1500мс. Общий pool других продуктов не менялся.
Новый полный прогон на финальной версии завершён успешно:520тестов.

Независимый read-only аудит не обнаружил потери допустимых решений при
BitSet conflict folding/Hall/union pruning. В inspector добавляются
authored-clip-intervals-v1 с clip IDs/source index/source/output intervals,
чтобы будущая причинная диагностика не восстанавливала их из выборки PTS.
Это authored provenance, не измерение декодированных пикселей. Три отдельные
unit-проверки не заменяют фактическую проверку этих полей в новом экспорте.

Sigma остаётся заблокирована и не дорабатывается. Публичные видео не
используются. После прежнего Heartbeat(B) проведены новые Heartbeat(A),
Heartbeat(B) на0.1.2; отдельный FEAR replay не создавал монтажа. Пара знакомая,
не sealed holdout. Общая цель и новые человеческие формы не закрываются.
