# «Под свою музыку»: интеграция для тестового MVP

Пользовательский путь: свой MP3/WAV → начало трека → автоматический монтаж →
«Довести монтаж» → подрезка/порядок клипов и музыка → новая версия MP4.
Дизайн использует существующие светлые поверхности, типографику и оранжевый
акцент; импорт, сдвиг и прослушивание находятся в разделе музыки.

База: main f96dcc54 + существующая объединённая сборка PR48 13726927.
Используются HybridProjectStore/Codec, ProjectAssetStore, существующий
EditableMontageImporter/Compiler и MediaCodecSpeedRampRenderer. Нового
хранилища, формата проекта или движка рендера нет.

Шаги реализации:
1. Сохранять победивший граф своей музыки и физические копии исходников в
   общем проекте; связать результат MP4 с проектом и кнопкой доводки.
2. Синхронизировать ProjectMusic и AudioTrack при замене трека/начала;
   сохранить undo/redo, повторное открытие и исходную автосборку.
3. Добавить управление музыкой в существующую ручную доводку. Для графов
   своей музыки использовать общий компилятор и существующий полный рендер
   с анализом; ограниченный analysis-free prepared export остальных проектов
   остаётся доступным на прежних условиях.
4. Проверить импорт/ошибку импорта, сохранение/правки/открытие, настоящий
   экспорт с ненулевым началом и приложить APK/скриншоты из CI.

В этом MVP предпросмотр ручной версии требует полного рендера. Экспорт
произвольного окна с ненулевым музыкальным стартом остаётся явно запрещён.
Нативная проверка на эмуляторе не заменяет тест на телефоне и оценку монтажа.
