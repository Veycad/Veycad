# Исправления по ревью Sigma — 18 сентября 2026

## Изменения

- Зеркальная пара и финальная сцена строятся в выходных UV (`vOutputTexCoord`). Координаты выборки видео переводятся в исходник через `uIncomingCrop`; маска следует тем же координатам. Для пары crop применяется к отклонению от якоря лица, поэтому центры половин остаются внутри выходного кадра при landscape/square/portrait.
- Ожидаемая маска финала учитывает масштаб 0,72, положение центра, обрезку и мягкие границы shader, затем камеру клипа. `SigmaComposition` содержит общие константы масштаба/центра и CPU-проекцию маски для QA. Обычная маска вступления сохраняет прежнюю геометрию.
- Зеркальная пара Sigma не планирует и не декодирует второй источник. Inspector больше не требует от неё разнесённых PTS. Общая зеркальная ветка других стилей и двойная экспозиция сохраняют второй источник.
- Показатель повторяющихся градиентов двойной экспозиции остаётся диагностическим полем отчёта. Ложный порог удалён из acceptance и его настроек. Это не новый измеритель художественного качества: Inspector подтверждает исполнение двухисточникового эффекта, но сходство с референсом требует просмотра.
- При выбранном варианте Sigma director строит только этот вариант. Автоматический выбор сохраняет все три. Подготовка других авторских рецептов не изменена.
- Постоянный знаменатель интеграла скорости вычисляется один раз на клип в рамках построения плана.

Сохранены проверки независимого второго источника двойной экспозиции; обновлены ожидания профиля и диагностического показателя.

Исправления не меняют отбор исходных сцен и не добавляют отсутствующий в материале полный рост. Ускорение по времени не измерено. Рабочее дерево содержит предшествующие изменения других задач; они не отменялись.
