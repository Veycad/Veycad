# Центрирование портретного просмотра: 0.1.15

На Samsung Galaxy A25 (SM-A256E), Android 16 / API 36, установленная cameraPilot 0.1.8 обновлена до 0.1.14 без удаления данных. SHA установленной ARM64 APK совпал с проверенной сборкой. Сохранённая FEAR / BEST_TAKE сессия открылась из «Эдитов». Её 28966 мс включают только первый полный проход; запись остановлена до второго. Исходный SHA-256 не изменился при обновлении, независимый FFmpeg полностью прочитал 869 кадров AVC, 1080×1920. Проверяется прежняя запись, а не новая съёмка в 0.1.14. Файл и снимки с человеком остаются только в ignored `artifacts/camera-samsung-014/`.

## Дефект и исправление

`VideoView` сохранял пропорции портретного исходника, но располагал его у левого края широкой карточки. В 0.1.15 изображение центрируется в той же карточке. Код записи, исходные байты, рамка живой камеры и требования материала не меняются.

Тест `CaptureReviewScreenTest#savedPortraitPreviewIsCenteredBeforeAndAfterRecreation` создаёт и открывает настоящий портретный AVC. Он ждёт размеров декодированного видео, проверяет центр по обеим осям и границы карточки, повторяет проверку после пересоздания Activity и сравнивает исходные байты. До исправления: `left=0, width=240, frame=632`, 1 failure / 4.311 с (`centering-red.txt`, `centering-red.png`). С исправлением: 1/1 за 4.845 с (`centering-green.txt`, `centering-green.png`). Изображения здесь синтетические, без пользовательского видео.
